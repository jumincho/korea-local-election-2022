# korea-local-election-2022

韓国の第8回地方選挙（2022年6月）を R で広域自治体ごとに分析し、2018年の地方選挙および2022年3月の大統領選挙と比較します。

## 概要

2022年6月1日、韓国では第20代大統領選挙から3か月足らずで第8回全国同時地方選挙が行われました。このプロジェクトでは、17の広域自治体（以下「市・道」：ソウル、6つの広域市、世宗、9つの道）の結果について、次の点を調べます。

- 各広域自治体首長選挙で誰が勝ち、どれだけの差をつけたか
- 主要政党の得票率が2018年の第7回地方選挙からどう変わったか
- 首長選挙の得票が大統領選挙の得票にどれだけ近かったか
- 性別・年齢層別の出口調査の得票率
- 基礎自治体の首長と地方議会の議員に当選した人の政党構成

データは文書化された整然データ（tidy data）の表で、2022年の元ファイルと一致することをテストで確かめています。R のコードは、この README のすべての図とすべての数値を再生成します。

## 主な結果

ここに示す数値はすべて `make figures` で計算して [`results/key_statistics.csv`](results/key_statistics.csv) に保存しており、CI がプッシュのたびにこのファイルを確認します。各市・道は人口にかかわらず同じ重みで数えます。

- **首長選挙**：2018年は17の広域自治体首長選挙で、共に民主党（DPK）が14、自由韓国党（LKP）が2、無所属候補が1（済州）を制しました。2022年は国民の力（PPP）が12、共に民主党が5を制しました。（[図1](#1-市道別の勝利政党)）
- **2022年の得票差**：5ポイント未満の差で決着した選挙は2つで、京畿道では共に民主党が0.15ポイント、大田では国民の力が2.39ポイント上回りました。最も大きな差は、全羅北道での共に民主党の64.23ポイントと、大邱での国民の力の60.78ポイントでした。（[図2](#2-2022年の得票差)）
- **2018年からの変化**：共に民主党の首長選挙での得票率は17市・道のうち15で下がり、中央値で見ると13.11ポイントの下落でした。最も大きく下がったのは世宗で、24.14ポイントの下落です。全羅北道と済州では上がりました。主要な保守政党（2018年は自由韓国党、2022年は国民の力）の得票率は、両方の選挙で候補者を立てた15の市・道すべてで上がりました。上昇幅が最も小さかったのは京畿道の13.40ポイント、最も大きかったのは2018年に無所属候補が勝った済州の36.22ポイントです。（[図3](#3-2018年からの変化)）
- **大統領選挙と首長選挙の得票率**：市・道ごとに見ると、各党の2022年6月の首長選挙での得票率は、2022年3月の大統領選挙での得票率とよく連動していました。17市・道についてのピアソンの相関係数は、共に民主党が r = 0.97（95%信頼区間 0.93〜0.99）、国民の力が0.98（0.96〜0.99）です。重み付けなしの平均では、共に民主党の首長候補の得票率は同党の大統領選挙での得票率を3.0ポイント下回り、国民の力の候補は4.6ポイント上回りました。（[図4](#4-大統領選挙と首長選挙の得票率)）
- **2018年と2022年の首長選挙の得票率**：2回の地方選挙の間では得票率の一貫性がこれより低く、共に民主党が r = 0.77（0.46〜0.91、17市・道）、自由韓国党／国民の力が0.87（0.64〜0.96、15市・道）でした。（[図5](#5-2018年と2022年の首長選挙の得票率)）
- **出口調査**：男女差が最も大きかったのは20代の有権者で、男性は65.1%が国民の力に、32.9%が共に民主党に投票し、女性は66.8%が共に民主党に、30.0%が国民の力に投票しました。性別・年齢層で分けた12グループのうち、共に民主党がリードしたのは5グループで、40代と50代の男性、20代・30代・40代の女性です。投票率は29.7%（20代男性）から73.9%（60代と70代の男性。元データでは両者が同じ数値）まででした。（[図6](#6-性別年齢層別の出口調査)）
- **地方公職**：基礎自治体首長に占める共に民主党の割合は2018年の66.81%から2022年の27.88%に、自由韓国党／国民の力の割合は23.45%から64.16%になりました。広域議会では、共に民主党の割合が78.65%から36.72%に、自由韓国党／国民の力の割合が16.53%から61.57%になりました。（[図7](#7-獲得した地方公職)）

2022年の元ファイルは、そこから整然データの表を作るスクリプトと一緒に [`data-raw/`](data-raw) に変更せずに保存してあり、すべての値が変わらずに引き継がれていることをテストで確認しています。データを使う前に知っておくべき点は次のとおりです。

- 得票の少ない一部の候補者が含まれていないため、いくつかの選挙では得票率の合計が100になりません。忠清南道の2022年の選挙は合計が100.04で、値が1つ誤入力されている可能性がありますが、記録どおりに残しています。
- 元データでは、出口調査の投票率が60代と70代のグループで同じです。
- 2018年、自由韓国党は光州と全羅南道に候補者を立てておらず、済州の2018年の選挙では無所属候補が勝ちました。
- 当選者の数値は議席の割合であり、得票の割合ではありません。

完全なデータ辞書、来歴、[注意点](data/README.md#caveats)は [`data/README.md`](data/README.md) にあります。

## 手法

- **結合には公式の市・道コードを使います**。すべての表と境界データは2桁の市・道コード（`CTPRVN_CD`）を共有しており、[`R/data.R`](R/data.R) の読み込み関数は未知のコード、政党、選挙を拒否します。行の順序で照合している箇所はありません。
- **定義**：勝者は得票率が最も高い候補者です。*得票差*は国民の力の得票率から共に民主党の得票率を引いた値で、単位はパーセントポイントです。*変化*はある政党の2022年の得票率から2018年の得票率を引いた値で、自由韓国党（2018年）と国民の力（2022年）を1つの保守政党として扱います。候補者を立てなかった政党には得票率がなく、したがって変化もありません。ゼロとしては数えません。
- **相関係数**は市・道単位で求めたピアソンの r で、95%信頼区間は `cor.test()`、最小二乗法による回帰直線は `lm()` で求めます。各市・道は人口にかかわらず1回ずつ数えます。点が17個（保守政党の2018年と2022年の比較では15個）しかないため、信頼区間は広くなります。相関係数が表すのは得票の地理的な分布であり、個人がどう投票したかではありません。
- **境界**：元データでは、隣接する市・道の境界線が一致していません。これを正しいカバレッジに整えたうえで、共有する境界線を1本ずつ200 mの許容誤差で簡略化するため、隣接する市・道は引き続き正確に接します。これによりファイルは13 MBから564 KiBになり、どの市・道の面積も0.4%を超えて変わりません。[`data/README.md`](data/README.md#boundaries) を参照してください。
- **図**は ggplot2 で英語のラベルを使って作成しているため、CJK フォントは不要です。共に民主党の青と自由韓国党／国民の力の赤は、1型2色覚と2型2色覚をシミュレーションしても区別できます。その他の政党はニュートラルなグレーで示し、色には必ず凡例か直接ラベルを添えています。

```
.
├── R/                         関数（スクリプトとテストから source で読み込む）
│   ├── data.R                 整然データの読み込みと検証
│   ├── analysis.R             勝者、得票差、変化、相関
│   ├── summary.R              この README で引用する主要な統計量
│   ├── theme.R                色、ggplot2 のテーマ、PNG 出力
│   └── plots.R                図ごとに1つの関数
├── data/                      整然データ（data/README.md を参照）
│   └── geo/provinces.geojson  簡略化した境界
├── data-raw/                  元の入力データと data/ を作るスクリプト
│   ├── original/              2022年の CSV ファイル（変更なし）
│   └── shapefile/             市・道の境界ファイル（変更なし）
├── scripts/make_figures.R     figures/ と results/ を再生成
├── figures/                   上の図（PNG、200 dpi）

├── DESCRIPTION                R の依存パッケージ
├── Makefile                   make data | figures | test | lint
└── .github/workflows/ci.yml   プッシュごとに lint、テスト、再構築を実行
```

## 再現方法

R 4.1 以降と、[`DESCRIPTION`](DESCRIPTION) に記載されたパッケージが必要です。CI で使っている Ubuntu 24.04 では、すべて Ubuntu のアーカイブから入手できます。

```sh
sudo apt-get install -y --no-install-recommends \
  r-base-core r-cran-sf r-cran-ggplot2 r-cran-dplyr r-cran-tidyr r-cran-readr \
  r-cran-patchwork r-cran-ggrepel r-cran-scales r-cran-testthat r-cran-lintr \
  r-cran-ragg r-cran-here
```

それ以外の環境では CRAN からインストールしてください（sf には GDAL、GEOS、PROJ が必要ですが、CRAN の macOS 版と Windows 版のビルドにはこれらが含まれています）。

```sh
Rscript -e 'install.packages("remotes"); remotes::install_deps(dependencies = TRUE)'
```

その後、リポジトリのルートで次を実行します。

```sh
make figures   # figures/*.png と results/key_statistics.csv
make test      # テストスイート
make lint      # lintr（.lintr の設定を使用）
make data      # data-raw/ の元ファイルから data/ を再構築
```

`make` を使わない場合は、`Rscript scripts/make_figures.R` と `Rscript tests/testthat.R` を実行します。
