# korea-local-election-2022

대한민국 제8회 전국동시지방선거(2022년 6월)를 R을 이용해 시도 단위로 분석하고,
2018년 지방선거 및 2022년 3월 대통령선거와 비교합니다.

[![CI](https://github.com/jumincho/korea-local-election-2022/actions/workflows/ci.yml/badge.svg)](https://github.com/jumincho/korea-local-election-2022/actions/workflows/ci.yml)

## 개요

2022년 6월 1일, 대한민국은 제20대 대통령선거를 치른 지 석 달이 채 지나지 않아
제8회 전국동시지방선거를 실시했습니다. 이 프로젝트는 17개 광역자치단체(이하 ‘시도’:
서울특별시, 6개 광역시, 세종특별자치시, 9개 도)의 결과에서 다음을 살펴봅니다.

- 각 광역자치단체장 선거에서 누가 얼마만큼의 차이로 이겼는지
- 주요 정당별 득표율이 2018년 제7회 전국동시지방선거 이후 어떻게 바뀌었는지
- 광역자치단체장 선거의 득표가 대통령선거의 득표를 얼마나 가깝게 따라갔는지
- 성별·연령대별 출구조사 득표율
- 기초자치단체장과 지방의회의원 당선인의 정당 구성

데이터는 문서화된 tidy 형식의 표이며, 2022년 원본 파일과 일치하는지 확인하는
테스트가 함께 있습니다. R 코드는 이 README의 모든 그림과 모든 수치를 다시 생성합니다.

## 주요 결과

여기에 나오는 모든 수치는 `make figures`가 계산해
[`results/key_statistics.csv`](results/key_statistics.csv)에 저장하며, CI가 푸시할 때마다
이 파일을 확인합니다. 시도는 인구와 관계없이 모두 같은 비중으로 셉니다.

- **광역자치단체장 선거**: 2018년에는 17개 광역자치단체장 선거 가운데
  더불어민주당(DPK)이 14곳, 자유한국당(LKP)이 2곳, 무소속 후보가 1곳(제주특별자치도)에서
  이겼습니다. 2022년에는 국민의힘(PPP)이 12곳, 민주당이 5곳에서 이겼습니다.
  ([그림 1](#1-시도별-당선-정당))
- **2022년 득표율 격차**: 5%p 미만의 차이로 승부가 갈린 선거는 두 곳이었습니다.
  경기도에서는 민주당이 0.15%p, 대전광역시에서는 국민의힘이 2.39%p 앞섰습니다.
  격차가 가장 컸던 곳은 민주당이 64.23%p 앞선 전라북도와 국민의힘이 60.78%p 앞선
  대구광역시였습니다. ([그림 2](#2-2022년-득표율-격차))
- **2018년 대비 변화**: 민주당의 광역자치단체장 선거 득표율은 17개 시도 중 15곳에서
  떨어졌고, 중앙값으로 보면 13.11%p 하락했습니다. 가장 크게 떨어진 곳은
  세종특별자치시로, 24.14%p 하락했습니다. 전라북도와 제주특별자치도에서는 올랐습니다.
  주요 보수 정당(2018년 자유한국당, 2022년 국민의힘)의 득표율은 두 선거에 모두 후보를
  낸 15개 시도 전부에서 올랐습니다. 상승 폭은 경기도가 13.40%p로 가장 작았고, 2018년에
  무소속 후보가 이겼던 제주특별자치도가 36.22%p로 가장 컸습니다.
  ([그림 3](#3-2018년-대비-변화))
- **대통령선거와 광역자치단체장 선거 득표율**: 시도별로 보면 각 정당의 2022년 6월
  광역자치단체장 선거 득표율은 2022년 3월 대통령선거 득표율을 밀접하게 따라갔습니다.
  17개 시도에 대한 피어슨 상관계수는 민주당 r = 0.97(95% 신뢰구간 0.93\~0.99),
  국민의힘 0.98(0.96\~0.99)입니다. 가중치를 두지 않은 평균으로 보면 민주당
  광역자치단체장 후보의 득표율은 같은 당의 대통령선거 득표율보다 3.0%p 낮았고,
  국민의힘 후보는 4.6%p 높았습니다. ([그림 4](#4-대통령선거와-광역자치단체장-선거-득표율))
- **2018년과 2022년 광역자치단체장 선거 득표율**: 두 지방선거 사이에서는 득표율의
  일관성이 이보다 낮았습니다. 민주당은 r = 0.77(0.46\~0.91, 17개 시도),
  자유한국당/국민의힘은 0.87(0.64\~0.96, 15개 시도)입니다.
  ([그림 5](#5-2018년과-2022년-광역자치단체장-선거-득표율))
- **출구조사**: 남녀 차이는 20대 유권자에서 가장 컸습니다. 20대 남성은 65.1%가
  국민의힘에, 32.9%가 민주당에 투표했고, 여성은 66.8%가 민주당에, 30.0%가 국민의힘에
  투표했습니다. 성별·연령대로 나눈 12개 집단 가운데 민주당이 앞선 집단은 5개로,
  40대·50대 남성과 20대·30대·40대 여성입니다. 투표율은 29.7%(20대 남성)에서
  73.9%(60대·70대 남성, 원자료에서 두 집단이 같은 값을 공유함)까지였습니다.
  ([그림 6](#6-성별연령대별-출구조사))
- **지방 선출직**: 기초자치단체장 가운데 민주당 소속 비율은 2018년 66.81%에서 2022년
  27.88%로, 자유한국당/국민의힘 소속 비율은 23.45%에서 64.16%로 바뀌었습니다.
  광역의회에서는 민주당의 비율이 78.65%에서 36.72%로, 자유한국당/국민의힘의 비율이
  16.53%에서 61.57%로 바뀌었습니다. ([그림 7](#7-지방-선출직-당선-결과))

변경 없이 보관되어 있으며, 모든 값이 바뀌지 않고 옮겨졌는지 테스트로 확인합니다.
데이터를 쓰기 전에 알아 둘 점은 다음과 같습니다.

- 원자료에서 출구조사 투표율은 60대와 70대 집단이 같습니다.

  제주특별자치도의 2018년 선거에서는 무소속 후보가 이겼습니다.
- 당선인 수치는 득표가 아니라 의석의 비율입니다.

## 방법

- **조인에는 공식 시도 코드를 사용합니다.** 모든 표와 경계 데이터는 두 자리 시도
  코드(`CTPRVN_CD`)를 공유하며, [`R/data.R`](R/data.R)의 읽기 함수는 알 수 없는 코드,
  정당, 선거를 거부합니다. 행 순서로 짝을 맞추는 부분은 없습니다.
- **정의**: 당선자는 득표율이 가장 높은 후보입니다. *격차*는 국민의힘 득표율에서
  민주당 득표율을 뺀 값이며, 단위는 퍼센트포인트(%p)입니다. *변화*는 한 정당의 2022년
  득표율에서 2018년 득표율을 뺀 값으로, 자유한국당(2018년)과 국민의힘(2022년)을 하나의
  보수 정당으로 봅니다. 후보를 내지 않은 정당은 득표율이 없으므로 변화도 없으며, 0으로
  치지 않습니다.
- **상관계수**는 시도 단위로 계산한 피어슨 r이며, 95% 신뢰구간은 `cor.test()`로,
  최소제곱 회귀선은 `lm()`으로 구합니다. 각 시도는 인구와 관계없이 한 번씩만 셉니다.
  점이 17개(보수 정당의 2018-2022 비교에서는 15개)뿐이라 신뢰구간이 넓습니다.
  상관계수는 득표의 지리적 분포를 설명할 뿐, 개인이 어떻게 투표했는지를 보여 주지는
  않습니다.
- **경계**: 원자료에서는 이웃한 시도의 경계선이 서로 맞지 않습니다. 이를 올바른
  커버리지로 정리하고, 공유 경계를 하나씩 200 m 허용 오차로 단순화하므로 이웃한 시도는
  여전히 정확히 맞닿습니다. 이 과정에서 파일은 13 MB에서 564 KiB로 줄고, 어느 시도의
  면적도 0.4%를 넘게 바뀌지 않습니다. [`data/README.md`](data/README.md#boundaries)를
  참고하세요.
- **그림**은 ggplot2로 그리며 라벨이 영어이므로 CJK 글꼴이 필요하지 않습니다. 민주당의
  파란색과 자유한국당/국민의힘의 빨간색은 적색맹과 녹색맹 시뮬레이션에서도 구별됩니다.
  그 밖의 정당은 중립적인 회색으로 표시하며, 색에는 항상 범례나 직접 라벨이 함께
  붙습니다.

## 프로젝트 구조

```
.
├── R/                         함수(스크립트와 테스트가 source로 불러옴)
│   ├── data.R                 tidy 데이터 읽기와 검증
│   ├── analysis.R             당선자, 격차, 변화, 상관계수
│   ├── summary.R              이 README에 인용한 주요 통계
│   ├── theme.R                색상, ggplot2 테마, PNG 출력
│   └── plots.R                그림마다 함수 하나
├── data/                      tidy 데이터(data/README.md 참고)
│   └── geo/provinces.geojson  단순화한 경계
├── data-raw/                  원본 입력 자료와 data/를 만드는 스크립트
│   ├── original/              2022년 CSV 파일(변경 없음)
│   └── shapefile/             시도 경계 파일(변경 없음)
├── scripts/make_figures.R     figures/와 results/를 다시 생성
├── figures/                   위의 그림(PNG, 200 dpi)
├── results/key_statistics.csv 위에서 인용한 수치
├── tests/                     testthat 테스트 스위트(tests/testthat.R로 실행)
├── docs/presentation.pptx     발표 슬라이드
├── DESCRIPTION                R 의존 패키지
├── Makefile                   make data | figures | test | lint
└── .github/workflows/ci.yml   푸시할 때마다 린트, 테스트, 재생성
```

## 재현 방법

R 4.1 이상과 [`DESCRIPTION`](DESCRIPTION)에 나열된 패키지가 필요합니다. CI에서 사용하는
Ubuntu 24.04에서는 모든 패키지를 Ubuntu 아카이브에서 설치할 수 있습니다.

```sh
sudo apt-get install -y --no-install-recommends \
  r-base-core r-cran-sf r-cran-ggplot2 r-cran-dplyr r-cran-tidyr r-cran-readr \
  r-cran-patchwork r-cran-ggrepel r-cran-scales r-cran-testthat r-cran-lintr \
  r-cran-ragg r-cran-here
```

다른 환경에서는 CRAN에서 설치합니다(sf에는 GDAL, GEOS, PROJ가 필요하며, CRAN의 macOS
및 Windows 빌드에는 이들이 포함되어 있습니다).

```sh
Rscript -e 'install.packages("remotes"); remotes::install_deps(dependencies = TRUE)'
```

그런 다음 저장소 루트에서 다음을 실행합니다.

```sh
make figures   # figures/*.png와 results/key_statistics.csv
make test      # 테스트 스위트
make lint      # lintr(.lintr의 설정 사용)
make data      # data-raw/의 원본 파일로 data/를 다시 생성
```

`make`를 쓰지 않을 때는 `Rscript scripts/make_figures.R`과 `Rscript tests/testthat.R`을
실행합니다.
